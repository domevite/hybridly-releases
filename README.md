# Hybridly – download e aggiornamenti

Hybridly è un'app Windows per tenere il conto delle giornate di presenza in ufficio nel lavoro ibrido.
Questa repository contiene solo i pacchetti di installazione e di aggiornamento.

## Installazione

1. Scarica [Hybridly-win-Setup.exe](https://github.com/domevite/hybridly-releases/releases/latest/download/Hybridly-win-Setup.exe).
2. Eseguilo: l'installazione è a un clic e non richiede permessi di amministratore.
3. Se Windows mostra l'avviso SmartScreen (l'installer non è firmato): "Ulteriori informazioni" → "Esegui comunque".

Hybridly compare nel menu Start. I dati restano solo sul tuo PC.

## Aggiornamenti

L'app controlla questa repository a ogni avvio: quando è disponibile una nuova versione la scarica
e mostra il tasto "Aggiorna alla versione X" nel menù laterale.

Tutte le versioni: [Releases](https://github.com/domevite/hybridly-releases/releases).
